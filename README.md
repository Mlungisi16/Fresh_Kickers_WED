# FreshKickers

## Walk It Like You Talk It 👟

FreshKickers is a modern sneaker cleaning and customisation website created for customers who want to keep their sneakers clean, fresh and unique.

The website provides information about FreshKickers services and allows customers to explore sneaker washing, custom sneaker designs, place orders and book appointments.

---

## Project Description

FreshKickers is a sneaker care and customisation business based in Kensington, Johannesburg.

The website was designed to give customers an easy way to learn about the business, view available services, check prices and contact FreshKickers.

The website uses a modern dark design with green accents to create a professional sneaker-focused appearance.

---

## Purpose of the Website

The purpose of the FreshKickers website is to:

* Promote FreshKickers online.
* Provide information about the business.
* Display sneaker cleaning services.
* Display sneaker customisation services.
* Display service prices.
* Allow customers to place orders.
* Allow customers to book appointments.
* Provide pickup and delivery options.
* Allow customers to contact FreshKickers.
* Provide a professional and easy-to-use website.

## Order System

Customers can place an order through the Services page.

The order form allows customers to provide information about their sneakers and the service they require.

Customers can select:

* Sneaker Wash.
* Custom Sneaker Design.
* Sneaker brand.
* Number of pairs.
* Custom design style.
* Pickup or delivery.
* Order details.

An order number is provided after an order has been submitted.

---

## Pickup and Delivery

FreshKickers provides customers with two options for getting their sneakers to the business.

### Bring Sneakers

Customers can bring their sneakers to FreshKickers themselves.

### Pickup & Delivery

Customers can request pickup and delivery.

An additional **R50** is charged for the pickup and delivery service.

Customers selecting this option must provide their address.
